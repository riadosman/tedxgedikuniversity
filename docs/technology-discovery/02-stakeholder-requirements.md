## Cross-stakeholder acceptance

- Every critical operational task has one accountable human and a deputy; product roles do not invent actual appointments.
- An attendee sees whether a request is pending, waitlisted or confirmed; staff can explain the same state from their view.
- A department leader cannot retrieve another department's private members by changing a URL, filter, API payload, file ID or export request.
- Production receives the approved presentation version without access to attendee exports or confidential fact-checking evidence by default.
- University/venue receive only an approved extract with a recorded purpose; being an institutional stakeholder does not grant all-data access.
- Physical emergencies use venue procedures and direct communication first; logging an incident is not a substitute for calling for help.
