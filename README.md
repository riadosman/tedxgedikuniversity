# TEDxGedik University

TEDxGedik University web sitesi ve etkinlik yönetim platformu. Django ile geliştirilmiş uygulama; etkinlik sayfalarını, kayıt ve bilet işlemlerini, QR ile giriş kontrolünü ve gönüllü ekip yönetimini içerir.

## Kurulum

- [Uygulama ve hızlı başlangıç](platform/README.md)
- [Yerel geliştirme kurulumu](docs/development/local-setup.md)
- [Mimari](docs/architecture/platform.md)
- [Test ve kalite kontrolleri](docs/development/code-quality.md)
- [Üretim ortamına kurulum](docs/deployment/production.md)

Python 3.11 veya üstü ve PostgreSQL gereklidir. Ortam değişkenleri için [örnek yapılandırmayı](platform/.env.example) kullanın; gerçek anahtarları proje kökündeki yerel `.env` dosyasına yazın.

Bu repo kaynak kodunu içerir. Uygulamayı çalıştırmak için Python uygulama sunucusu ve PostgreSQL gerekir; GitHub Pages üzerinde doğrudan çalışmaz.

Yerel veritabanları, kullanıcı yüklemeleri, erişim anahtarları ve özel organizasyon belgeleri repoya dahil edilmez.
